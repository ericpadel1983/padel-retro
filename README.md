# Pádel Retro

Starter de una aplicación React con Vite para un juego de pádel arcade con estética retro.

## Requisitos

- Node.js 20.19+ o 22.12+

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

## Estado

La interfaz base incluye una pantalla responsive, ilustración de pista, botón para generar un código de sala y formulario de acceso. La creación y unión son demostrativas: el juego online, la sincronización en tiempo real y el servidor de salas todavía no están implementados.
